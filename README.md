# Customer-Satisfaction-Prediction-1
This is a Data Science Project....
This project focuses on analyzing and predicting customer satisfaction based on support ticket data. It uses a variety of data science libraries for data exploration, preprocessing, and model building.

Key Features
Data Preprocessing: The notebook handles missing values and encodes categorical features.

Exploratory Data Analysis (EDA): It includes visualizations to understand the distribution of customer satisfaction ratings and other key variables.

Machine Learning Models: It builds and evaluates multiple classification models, including Random Forest Classifier, Logistic Regression, and Support Vector Machine (SVC) to predict customer satisfaction ratings.

Performance Evaluation: The models are evaluated using metrics such as accuracy score, classification report, and confusion matrix.
